# Credential Extraction Assistant

Streamlit application for extracting structured information from scanned business/project PDFs using Google Gemini, with persistent user data in Supabase.

## Current phase
Phase 1 — Project Foundation.

## Planned stack
- Python 3.12
- Streamlit
- Google Gemini
- Supabase PostgreSQL
- Supabase Storage
- Pandas
- OpenPyXL
- GitHub
- Streamlit Community Cloud

## Important
Supabase will be the permanent source of truth. Streamlit session state is temporary UI state only. Excel is the schema template and user export.
